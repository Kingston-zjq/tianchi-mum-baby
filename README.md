# 天池母婴电商数据集分析

基于天池母婴电商数据集的销售趋势、类目结构与用户画像分析，包含 **15 张交互式图表** 的可视化看板。

## 📈 核心结论

| 指标 | 数值 |
|---|---|
| 总销量（清洗后） | 48,055 件 |
| 有效订单 / 用户 | 29,929 笔 / 29,902 人 |
| 数据周期 | 2012-07-02 ~ 2015-02-05（30 个完整月） |
| 客单件数 | 1.61 件/单 |
| 11 月销量贡献 | 12.0%（均匀分布基准 8.3%） |
| 头部类目集中度 | Top1 占 31.8%，Top3 合计 81.4% |
| 核心购买人群 | 6-12 月龄宝宝家庭 |

### 关键发现

1. **大促效应真实但非爆发式**：11 月销量 2,760 件，同比 1.6 倍（而非早期误判的 5 倍）
2. **增长来自大盘**：年度销量 5,742 → 15,800 → 23,740 件，三年增长 3 倍以上
3. **类目极度集中**：仅 6 个一级类目，Top3 贡献 81.4% 销量
4. **长尾型商品结构**：662 个二级类目中需 Top 121 个才达到 80% 销量
5. **6-12 月龄是黄金窗口**：与奶粉/辅食/纸尿裤消耗周期吻合
6. **女宝宝家庭高约 25%**：温和倾向，非结构性差异

### ⚠️ 数据质量提醒

`buy_mount` 字段存在 **42 笔 > 100 件的极端值**（单笔最大 10,000 件，而均值仅 2.54 件），单独贡献原销量的 37%。

若不做清洗，总销量会被高估至 76,250 件（真实值 48,055 件），且「双十一销量暴增 5 倍」的结论完全是脏数据假象。

另需注意：复购率仅 0.08% 是**抽样数据 user_id 近乎唯一**造成的，不可外推为业务判断；性别/月龄分析仅基于占总销量 2.36% 的关联子集（约 1,100 件）。

## 🔧 复现方式


- **渲染验证**：Playwright + 无头浏览器实测 SVG 渲染
